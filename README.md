# 宽 API Theme Kit

宽 API 的公开主题工作台和主题模板。它把现有主题、切换动画、普通对话、图片/产物面板、设置页和工程模式项目入口放在同一个可修改的演示里，方便其他人只改主题，不改产品逻辑。

本仓库是**主题和视觉资源仓库**，不包含 Sub2API、账号、API Key、数据库、聊天记录、附件、服务器配置或任何生产凭据。演示页不会连接模型，也不会上传附件。

## 在线试用

本地运行后访问 `http://127.0.0.1:5190/`。主题可以通过顶部切换，也可以用 URL：

```text
?theme=clear
?theme=folio
?theme=studio
?theme=canvas
?theme=native
?theme=mono
```

每个主题都支持浅色、深色和跟随系统。切换时会播放粒子散开动画；低性能设备自动减少粒子和时长，`prefers-reduced-motion` 开启时直接切换，不隐藏内容、不阻断键盘操作。

## 主题目录

| ID | 名称 | 视觉方向 | 当前覆盖 |
| --- | --- | --- | --- |
| `clear` | 澄明 | 留白、安静、轻量对话 | Chat、设置、文件/产物、Work |
| `folio` | 序页 | 编辑排版、阅读节奏 | Chat、设置、文件/产物、Work |
| `studio` | 工坊 | 高信息密度、工作台 | Chat、设置、文件/产物、Work |
| `canvas` | 场域 | 双区画布、并行创作 | Chat、设置、文件/产物、Work |
| `native` | 随行 | 移动优先、原生触感 | Chat、设置、文件/产物、Work |
| `mono` | 素境 | 当前独立 React 素境主题 | Chat；Work 入口使用同一主题令牌 |
| D 老师 | D Teacher | 线上经典生产主题 | `runtime/production/` 中的宿主扩展 |

`clear` 到 `native` 是可直接修改的主题工作台；`mono` 是当前素境构建产物的可运行副本；D 老师和素境的生产扩展资源保留在 `runtime/production/`，用于接入真实 Chat 宿主。

## 主题模板

开始新主题时复制：

```text
src/theme-template.js
src/theme-template.css
```

主题只负责颜色、字体、间距、圆角、阴影、布局密度和动效表现。宿主仍负责功能和数据。主题不应该添加新的 API、模型、工具或审批规则。

必须覆盖的视觉插槽：

- 外壳、侧栏、工具栏、顶部栏、面包屑和主题入口
- 对话历史、新对话按钮、分组选择、模型选择和思考强度滑块
- 用户消息、AI 消息、真实思考摘要、引用/来源、代码、公式和错误状态
- 输入框、附件托盘、发送/停止、取消、重试、复制、下载和编辑按钮
- 设置页、账户区、主题选择、浅色/深色/系统模式和保存状态
- 文件/产物面板、图片预览、专业生图等待态、进度和下载
- 工程模式项目入口、项目文件、计划、命令与结果、审批、终端、恢复/重试、项目输入框
- Toast、空状态、加载状态、网络错误、权限错误、窄屏和 reduced-motion 状态

模板里已经列出完整插槽，不要因为某个主题不常用就把关键控件删掉。可以改变呈现方式，例如把命令结果默认折叠、把设置做成侧栏，但不能隐藏功能状态。

## 文件结构

```text
src/app.js                 # 无网络的完整主题工作台演示
src/theme-transition.js    # GSAP 切换动画，含低性能和 reduced-motion 分支
src/theme-template.js      # 新主题的令牌和插槽契约
src/theme-template.css     # 新主题的最小 CSS 模板
public/styles.css          # 六套主题与 Chat/Work 所有可见表面的演示样式
runtime/production/        # 当前 D 老师/素境宿主扩展和现行切换动画
docs/theme-contract.md     # 详细的主题边界、功能矩阵和验收表
```

## 开发

需要 Node.js 18+：

```powershell
npm install
npm run build
npm start
```

公开仓库的构建只复制本仓库的 `public/`，不依赖用户电脑上的另一个项目，也不从线上下载字体、图片或脚本。

## 验收

至少检查：

```powershell
npm run verify
```

然后在浏览器里逐个切换六套主题，在桌面、平板和手机宽度检查：主题选择、浅深色、对话、文件面板、设置和工程项目入口。命令和结果、审批、计划、终端、图片进度都应该仍然可见且可展开。
